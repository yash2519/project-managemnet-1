# Unused Types Report

This report identifies TypeScript interfaces or types that are defined and exported but potentially unused across the codebase.

## Findings
Type and interface definitions are primarily centralized in two locations:
1. **Backend**: Automatically generated by Prisma (`@prisma/client`).
2. **Frontend**: Manually defined and exported in `client/src/state/api.ts`.

## Analysis of Frontend Types (`api.ts`)
The following interfaces are exported from `api.ts`:
- `ProjectOwner`
- `Project`
- `User`
- `FileUpload`
- `PresignedUrlResult`
- `Activity`
- `Attachment`
- `Task`
- `AIBreakdownSubtask`
- `SearchResults`
- `TeamMember`
- `Team`

**Results**: All exported interfaces are consumed internally within the `api.ts` file to properly type the RTK Query endpoints (e.g., `build.query<Project[], void>`). 

While some interfaces (like `PresignedUrlResult` or `ProjectOwner`) may not be imported directly by external UI components, they are critical for the internal typing of the API slice and cannot be considered "unused code".

## Recommendations
- For better code organization, as the `api.ts` file grows, consider extracting these interfaces into a dedicated `types/index.ts` file.
